# 🐍 LingX

**Интерактивный учебник Python, который работает прямо в браузере.**

LingX — это учебник для тех, кто хочет научиться программировать с нуля. Никаких установок: открыл страницу — и уже пишешь код. Теория простыми словами, каждое задание проверяется автоматически.

---

## ✨ Возможности

- **13 уроков, 42 задания** — от `print("Привет, мир!")` до генератора паролей
- **Код работает в браузере** — Python выполняется прямо на странице (Skulpt)
- **Автопроверка заданий** — правильно = зелёный, ошибка = красный с подсказкой
- **Подсветка кода** — редактор на CodeMirror, как в настоящей IDE
- **Вход по email** — код из письма + подтверждение ссылкой (Gmail SMTP)
- **Тёмная тема** по умолчанию, настройки и кастомизация
- **Прогресс** — решённые задания сохраняются за аккаунтом
- **Без установки** — всё работает в браузере бесплатно

## 🗂 Структура

```
lingx/
├── index.html          # Главная страница (хаб)
├── python/             # Учебник Python
│   └── index.html
├── api/                # Серверные функции (Vercel)
│   ├── send-code.js    # Отправка кода на email
│   ├── verify.js       # Проверка кода
│   ├── send-confirm.js # Ссылка подтверждения email
│   ├── confirm.js      # Страница подтверждения
│   ├── me.js           # Профиль и прогресс
│   └── _db.js          # База данных (GitHub as storage)
├── img/                # Логотипы
├── data/users.json     # Данные пользователей (DB)
└── vercel.json         # Конфигурация Vercel
```

## 🚀 Запуск

```bash
# Локально — просто открыть страницу
# или через сервер:
python -m http.server 8080
```

### Деплой на Vercel (для входа по email)

Нужны переменные окружения:

| Переменная | Описание |
|---|---|
| `GMAIL_USER` | Gmail отправителя (SMTP) |
| `GMAIL_APP_PASS` | Пароль приложения Gmail |
| `GH_TOKEN` | GitHub-токен для хранения базы |

```bash
vercel deploy
```

## 🛠 Что используется

- **Skulpt** — Python 3 в браузере
- **CodeMirror** — редактор с подсветкой
- **Nodemailer** — отправка писем через Gmail SMTP
- **GitHub API** — хранение данных пользователей
- **Vercel Functions** — серверные функции
